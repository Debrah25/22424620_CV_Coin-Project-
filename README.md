Coin Segmentation Project

Compares thresholding, region growing and k-means for segmenting and counting
coins in photos under different lighting/background/touching-coin conditions.

data/raw - the 24 test images (manifest.csv has the original filenames)
data/ground_truth - hand drawn masks used for evaluation
scripts - all the code
outputs - csv results + overlay figures, generated by the scripts
reports - final report

run from the project root, e.g:
python3 scripts/run_all.py
python3 scripts/evaluate.py
